# Ciltriq Technologies - Business Systems Engineering

## About

Ciltriq Technologies specializes in engineering business systems that eliminate operational chaos and unlock sustainable growth. We diagnose inefficiencies, automate operations, and build infrastructure that scales.

## Tech Stack

- **Framework**: React + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Animations**: Framer Motion

## Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```

## Build

```sh
# Build for production
npm run build
```
